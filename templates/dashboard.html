PrivateGPT dashboard

Prompt v{{ view.settings.DASHBOARD_PROMPT_VERSION }}

Everything above works without AI. When you want more — a summary of every thread, themes across them, suggested actions and draft replies — Jarvis can hand the whole overview to PrivateGPT in one prompt, and PrivateGPT returns it as a page you can work in.

  1. 1

    Copy the prompt

    It contains every item on your dashboard: subjects, people, days waiting and a short excerpt of each message.

  2. 2

    Paste it into PrivateGPT

    PrivateGPT answers with one block of HTML. Use its copy button to copy the whole block.

  3. 3

    Save it as a page

    Paste into Notepad and save as jarvis-overview.html (set "Save as type" to All files).

  4. 4

    Check it, then open it

    Pick the saved file here. Jarvis reads it on this computer and tells you whether it is safe to open. If it is, double-click the file; it opens in your browser and keeps your ticks for the day.

{{ icon('shield', 22) }}

How the page is kept from sending anything

The prompt requires this exact line at the top of the page:

{{ csp_line }}

It is a Content-Security-Policy. It makes the browser refuse everything the page tries to load or send — web fonts, scripts, images, frames, form posts, background requests — so an accidental link to the internet simply does nothing.

One thing a policy line cannot stop is a page moving itself to a different web address, which could carry data with it. That is what step 4 is for: Jarvis reads the file and refuses it if the policy line is missing or misplaced, if anything points outside the page, or if any script tries to navigate or open a window. Only open a page Jarvis has passed.
